
  # Enterprise Website UI Design

  This is a code bundle for Enterprise Website UI Design. The original project is available at https://www.figma.com/design/NN5yScew7nvT00jER8ASms/Enterprise-Website-UI-Design.

  ## Running the code

  Run `npm i` to install the dependencies.

  Run `npm run dev` to start the development server.

  Development output is written to `.next-dev`, separate from production output
  in `.next`, so building the project does not overwrite the running development server.

  Run `npm run build` to create a production build, then `npm start` to serve it.
